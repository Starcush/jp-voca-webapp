책의 내용을 단어장 앱에 어떻게 적용할지 논의한 기록입니다. 대화 전문을 그대로 보관하기보다, 다시 검토할 가치가 있는 가설과 논거를 구조화합니다.

## P-002 · 쓰레드의 목표 감정을 먼저 정의하기

- 날짜: 2026-08-07
- 상태: 논의 중
- 근거가 된 책 기록: B-002
- 관련 결정: 없음

**행동 문제**

정보가 유용하더라도 쓰레드가 어떤 감정을 전달하려는지 불분명하면, 독자가 자신과 관련된 내용으로 받아들이지 못하거나 다음 문장으로 자연스럽게 이어가지 못할 수 있다.

**논의 요약**

쓰레드를 쓰기 전에 독자가 느끼기를 바라는 감정을 한 문장으로 정한다. 각 문장은 그 감정과 모순되지 않아야 하며, 개별 쓰레드뿐 아니라 채널이 누적해 온 감정적 맥락과도 맞아야 한다.

**적용 가설**

초안 작성 전에 아래 두 문장을 채우고, 퇴고할 때 각 문장이 이에 부합하는지 확인한다.

- 이 쓰레드를 보는 사람이 느껴야 할 감정은 `[목표 감정]`이다.
- 이 쓰레드를 본 뒤 사용자에게 남기지 말아야 할 감정은 `[피할 감정]`이다.

쓰레드의 흐름에 따라 감정이 변한다면 시작, 본문, 마무리의 의도를 따로 적을 수 있다. 예를 들어 `공감 -> 이해 -> 시도해 볼 수 있다는 자신감`처럼 설계한다.

**위험과 윤리 점검**

- 내용에 근거하지 않은 불안, 긴급성 또는 기대를 만들지 않는다.
- 호기심을 만들기 위해 핵심 정보를 의도적으로 감추거나 오해를 유도하지 않는다.
- 반응 수나 클릭을 높이기 위한 감정과 독자에게 실제로 도움이 되는 감정을 구분한다.
- 채널의 감정적 일관성이 새로운 관점이나 정직한 표현을 막는 규칙이 되지 않게 한다.

**검증 방법**

- 게시 전: 목표 감정과 피할 감정을 말로 설명할 수 있는지 확인한다.
- 게시 후: 저장, 의미 있는 답글, 후속 행동과 함께 독자의 정성적 반응이 의도한 감정과 일치하는지 살핀다.
- 클릭이 늘더라도 오해, 실망, 불필요한 불안이 확인되면 실패로 판단한다.

**열린 질문**

- 이 앱 또는 채널이 장기적으로 쌓고 싶은 핵심 감정은 무엇인가?
- 모든 쓰레드에 하나의 감정만 둘 것인가, 감정의 흐름을 설계할 것인가?
- 게시 전 체크리스트로만 사용할지, 콘텐츠 기획 문서의 필수 항목으로 만들지 정해야 한다.

## P-003 · 앱의 메인 색과 제품 성격 검토

- 날짜: 2026-08-07
- 상태: 검증 필요
- 근거가 된 책 기록: B-009, B-010, B-011, B-012, B-013, B-014, B-015, B-016, B-017
- 관련 결정: 없음

**행동 문제**

현재 메인 색이 사용자가 앱에서 느껴야 할 감정과 일치하는지 정의하거나 검증하지 않은 상태다. 색을 관습적으로 적용하면 주요 행동, 선택 상태와 경고 상태가 사용자에게 어떤 의미로 보이는지 불명확해질 수 있다.

**현재 상태**

- 메인 색: 주황빛 빨강 `#FC4B1F`
- 밝은 배경색: `#FFF0EA`
- 진한 텍스트색: `#D83E18`
- 메인 색은 주요 CTA, 선택 상태, 진행률과 강조 정보에 폭넓게 사용된다.
- 전체 배경은 밝은 회색 `#F2F2F2`, 기본 텍스트는 거의 검정인 `#191919`이다.

현재 메인 색은 과거에 만들었던 와인 배달 앱의 색을 가져온 것이다. AI가 기본으로 생성한 색상보다는 만족스러웠지만, 실제 단어장 앱에서 사용하면서 학습 도구의 성격에 비해 강렬하다는 인상을 받았다. 따라서 현재 색의 사용 면적만 줄이는 방안뿐 아니라 메인 색 자체를 교체하는 방안도 실제 후보로 검토한다.

현재 색은 활력, 따뜻함과 행동성을 줄 수 있지만, 사용 맥락에 따라 긴급함이나 경고에 가깝게 느껴질 가능성도 있다. 코드의 `brand.green`, `brand.purple` 같은 과거 의미의 이름이 현재 실제 색과 일치하지 않아, 색 체계를 검토할 때 토큰 이름도 함께 정리할 필요가 있다.

**논의 요약**

메인 색 변경 여부를 색 선호만으로 결정하지 않는다. 먼저 이 앱을 반복해서 사용할 때 사용자가 느껴야 할 핵심 감정을 정의하고, 현재 색이 그 감정을 지원하는지 실제 주요 화면에서 확인한다.

단어장 앱의 현재 제품 방향을 기준으로 검토할 수 있는 감정 후보는 `부담 없이 다시 펼칠 수 있음`, `차분한 집중`, `작은 성취`, `발견의 즐거움`이다. 이는 아직 확정된 브랜드 정의가 아니라 논의를 위한 가설이다.

색이 공간의 체류 방식과 행동 속도에도 영향을 줄 수 있다는 관점을 추가한다. 앱에서도 OCR 저장처럼 빠른 진행이 필요한 화면과 단어 읽기·복습처럼 오래 집중해야 하는 화면의 색 역할이 다를 수 있다.

현재 색상 변경 여부와 최종 방향은 Part 2의 색 관련 내용을 더 읽은 뒤 종합하여 결정한다. 그전에는 특정 색상이나 팔레트를 채택하지 않는다.

카테고리에서 흔하지 않은 색은 차별화와 기억에 도움이 될 수 있지만, 단순히 달라 보이기 위한 색 선택은 근거로 삼지 않는다. 앱이 어떤 제품으로 인식되기를 바라는지 먼저 정하고, 그 포지션과 감정에 맞는 색을 선택한다.

현재 검토할 수 있는 포지션 후보는 다음과 같다.

- 빠르게 단어를 수집하는 실용적인 도구
- 차분하게 오래 공부하는 학습 공간
- 엄선된 해설과 콘텐츠를 제공하는 지적인 서비스
- 부담 없이 매일 돌아오는 친근한 개인 단어장

이 후보들은 서로 완전히 배타적이지 않지만, 색상 방향을 정할 때 무엇을 가장 우선할지는 별도로 결정해야 한다.

신뢰를 만드는 기반색과 행동을 강조하는 따뜻한 색의 역할을 분리하는 방안도 검토한다. 예를 들어 차분한 파랑·짙은 초록·차콜 같은 기반색 위에 현재 주황빛 빨강을 핵심 CTA와 성취 표현에 제한적으로 사용할 수 있다. 다만 파랑은 신뢰를 줄 수 있는 동시에 차갑고 흔한 기술 서비스처럼 보일 수 있으므로, 파랑을 선택한다면 밝기와 채도 또는 보조색으로 앱만의 인상을 만들어야 한다.

색을 선택한 최초의 이유보다 이후 일관되게 사용하며 의미를 쌓는 것이 중요하다는 관점도 반영한다. 충분히 검토해 색 체계를 정한 뒤에는 화면마다 임의로 다른 의미를 부여하지 않고 토큰과 사용 원칙을 유지한다.

색상 방향을 결정할 때는 다음 순서를 따른다.

1. 사용자가 느껴야 할 핵심 감정을 정의한다.
2. 일본어 학습 앱과 단어장 앱의 경쟁 색상을 조사한다.
3. 현재 색과 대안 색을 적용한 대표 화면 시안을 만든다.
4. 사용자 인상, CTA 발견성, 장시간 사용 피로와 접근성을 비교한다.
5. 기반색, 행동 강조색과 상태색의 역할을 토큰으로 고정한다.

레퍼런스의 색상 값만 복사하거나 개발자의 취향만으로 고르지 않는다. 팔레트는 필요한 상태를 구분할 수 있는 범위 안에서 단순하게 유지한다.

경쟁 색상 조사는 단어장 앱에만 한정하지 않는다. 유사한 단어장 서비스를 사용하는 사람을 주변에서 많이 관찰하지 못한 현재 상황을 고려하여, 사용자의 학습 시간과 습관을 놓고 경쟁하는 언어 학습 앱 전반으로 조사 범위를 넓힌다.

조사 대상은 다음 세 범주로 나눈다.

1. 일본어 단어장 및 암기 앱
2. 외국어 학습 앱
3. 문장, 독해와 복습 중심의 언어 학습 서비스

조사할 때 색상 값만 모으지 않고 각 서비스의 중심 감정, 주색과 보조색의 역할, CTA 색, 밝기·채도와 화면 내 사용 면적을 함께 기록한다.

색상 후보를 만들기 전에는 앱이 전달할 핵심 감정 세 가지와 그중 중심 감정 하나를 정한다. 현재 후보는 `차분한 집중`, `부담 없이 돌아오는 친근함`, `작은 성취감`, `발견의 즐거움`, `데이터와 학습 정보에 대한 신뢰`다.

색상 계열을 선택하는 일과 현재 색을 어디에 얼마나 사용하는지는 별개의 문제로 본다. 새 팔레트를 만들기 전에 대표 화면에서 주황빛 빨강이 사용되는 모든 요소를 조사하고, CTA·선택 상태·진행률·강조 정보가 서로 경쟁하는지 확인한다.

화면별 색 배치 감사 항목은 다음과 같다.

1. 사용자가 이 화면에서 취할 핵심 행동은 무엇인가?
2. 가장 강한 대비와 포인트 색이 그 행동에 사용되고 있는가?
3. 두 개 이상의 요소가 동시에 가장 중요해 보이지 않는가?
4. 보조 정보의 대비를 낮추더라도 읽기 쉬운가?
5. 선택의 정직성이 필요한 화면에서 특정 답을 부당하게 강조하지 않는가?

`60:30:10`은 엄격한 UI 면적 규칙이 아니라 강조의 희소성을 점검하는 참고 기준으로 사용한다. 복습 평가처럼 동등한 선택이 필요한 행동과 성공·경고·오류 같은 기능적 상태에는 브랜드 CTA와 다른 원칙을 적용한다.

대표 화면의 비교 시안에는 다음 후보를 포함한다.

1. 현재 밝은 회색 배경과 현재 주황빛 빨강 포인트
2. 따뜻한 오프화이트 배경과 현재 주황빛 빨강 포인트
3. 거의 흰색인 중립 배경과 현재 주황빛 빨강 포인트
4. 차분한 파랑·짙은 초록·차콜 기반의 대안 팔레트

특히 `무채색 또는 오프화이트 기반 + 주황빛 빨강 포인트`는 기존 브랜드 인상을 완전히 버리지 않으면서 차분한 학습 공간과 따뜻한 행동성을 분리할 수 있는 유력한 가설로 둔다. 주황빛 빨강은 핵심 CTA, 진행 완료와 작은 성취 표현에 제한하고 성공·경고·오류 상태색과는 구분한다.

색 체계를 정한 뒤에는 일관성을 통해 의미가 축적될 시간을 주되, `6개월 유지`를 고정 규칙으로 삼지는 않는다. 접근성, 오해 또는 사용성 문제가 발견되면 즉시 조정한다.

**1차 브랜드 인터뷰 결과**

앱이 전달해야 할 중심 감정과 역할을 다음과 같이 정리한다.

1. **중심 감정 — 차분한 몰입:** 단어를 입력하고 복습하며, 단어나 표현을 자세히 알아보는 동안 조금 더 오래 집중할 수 있어야 한다.
2. **보조 감정 — 탐구의 즐거움:** 공부가 지루하지 않고, 표현의 구성과 실제 쓰임을 알아가는 과정이 흥미로워야 한다.
3. **보조 감정 — 이해할 수 있다는 안도감:** 외국어 책과 낯선 표현 앞의 허들을 낮추고, 복잡한 내용을 혼자서도 이해해갈 수 있다는 감각을 줘야 한다.

피해야 할 감정은 `순간적인 충동`, `지루함`과 학습보다 친목·소셜 활동을 해야 할 것 같은 분위기다.

앱의 역할은 정답을 가르치고 시험을 감독하는 선생님보다 사용자의 실제 언어 이해를 돕는 조력자에 가깝다.

- 책 페이지 사진에서 여러 단어의 의미를 한꺼번에 파악해 외국어 독서의 진입 장벽을 낮춘다.
- 낯선 표현의 구성과 의미를 분석해 `왜 이런 뜻이 되는지` 이해하도록 돕는다.
- 단어만 암기하는 대신 적절한 난도의 예문을 통해 실제 사용 방법을 고민하게 한다.
- 하나의 기능만 제공하기보다 깊게 배우려는 사용자가 여러 각도에서 외국어를 이해하도록 지원한다.

행동 속도는 상황에 따라 구분한다. 사진·문장·단어 입력 과정은 빠르고 명확해야 하지만, 단어·표현의 분석과 예문을 살펴보는 화면은 천천히 머물 수 있어야 한다.

현재 주황빛 빨강은 개성과 에지가 있다는 장점이 있지만, 오래 머물고 싶은 차분한 분위기보다 활발한 교류나 즉각적인 행동에 가까운 인상을 준다는 의견이 있다. 따라서 이를 앱 전체의 메인 분위기로 유지하기보다 제한적인 강조색으로 남기거나, 에지를 유지하는 다른 색으로 교체하는 방안을 검토한다.

장기적으로는 `이 앱 덕분에 외국어 공부를 꾸준히 할 수 있었다`는 기억을 만드는 것이 목표다. 순간적인 참여보다 지속적인 사용과 이해의 축적을 색상 방향의 판단 기준으로 삼는다.

**적용 가설**

- 현재 주황빛 빨강을 유지하더라도 모든 강조 요소에 쓰지 않고, 사용자가 능동적으로 진행하는 핵심 행동에 제한하면 활력과 성취의 의미가 선명해질 수 있다.
- 차분함과 장시간 학습이 더 중요한 목표라면 중립색 또는 안정적인 색을 넓은 면적에 사용하고, 현재 메인 색은 작은 행동 강조색으로 사용하는 방법을 검토할 수 있다.
- 메인 색을 완전히 교체하기 전에 대표 화면 몇 개에서 색의 역할과 면적을 조정한 시안을 비교하는 것이 안전하다.

**2차 브랜드 인터뷰 결과**

앱이 실제 공간이라면 `채도가 높은 햇빛이 들지만 시원한 에어컨이 26도로 유지되는 카페`에 가깝다. 즐거운 대화는 방해가 되는 소음이 아니라 집중을 돕는 백색소음으로 들리고, 커피 향과 편안한 의자가 있어 오래 머물 수 있다. 향후 단어장 공유 기능도 조용히 고립된 공간보다 각자 공부하면서 느슨하게 연결된 공간의 이미지와 잘 맞는다.

이 비유에서 색의 역할을 두 층으로 나눈다.

- 넓은 면적의 기반색은 시원한 공기와 편안한 의자처럼 주의를 빼앗지 않는 `26도의 차분함`을 만든다.
- 제한적으로 쓰는 포인트 색은 창으로 들어오는 햇빛처럼 기쁨, 발견과 학습을 계속할 작은 동력을 만든다.

앱의 에지는 강한 색 자체가 아니라 사진과 대화형 프롬프트를 활용한 AI 조력 경험에 있다. 단어를 수동으로 하나씩 추가하는 앱이나 외국어 선생님을 연결하는 서비스와 달리, 사용자가 외국어를 실제로 이해하는 과정을 더 빠르고 깊게 돕는다는 차이를 화면의 구조와 상호작용으로 보여줘야 한다. 따라서 AI의 새로움을 표현하기 위해 화면 전체를 미래적이거나 고채도로 만들 필요는 없다.

현대적 또는 아날로그한 외형은 목적이 아니라 취향의 영역으로 본다. 어느 쪽을 선택하더라도 입력, 탐색과 복습의 사용성을 해치지 않아야 한다. 전체 분위기는 차분하게 유지하되 완료, 발견과 이해의 순간에는 명확한 기쁨을 표현한다.

**경쟁 앱 색상 관찰**

단어장에 한정하지 않고 현재 주요 언어 학습 서비스의 공식 화면을 비교했다.

- Duolingo는 밝은 초록을 중심으로 여러 고채도 보조색을 사용해 놀이, 캐릭터와 즉각적인 보상의 인상을 강하게 만든다.
- Babbel은 따뜻한 오프화이트 바탕과 오렌지레드 포인트를 사용하고, 실제 사람과 생활 이미지를 결합해 따뜻하고 현실적인 대화 학습의 인상을 만든다.
- Busuu는 넓은 면적의 선명한 파랑·보라 그라데이션과 밝은 초록 CTA를 사용해 기술적이고 역동적인 인상을 만든다.
- Memrise는 오프화이트 바탕과 짙은 네이비를 넓게 사용하고 노랑을 제한적으로 더해 안정감 속의 활기를 만든다.
- Quizlet을 포함한 학습 도구 범주에서는 파랑·보라 계열이 이미 자주 사용되므로, 평범한 고채도 파랑만 선택하면 개별 브랜드보다 `일반적인 학습 앱`으로 보일 위험이 있다.

따라서 이 앱은 경쟁 서비스의 고채도 주색 경쟁에 그대로 들어가기보다, 오래 머물 수 있는 낮은 자극의 기반과 햇빛 같은 기쁨의 포인트를 분리하는 방향이 유력하다. 차분한 청록·잉크 계열을 선택할 경우에도 Busuu 같은 전면 고채도 파랑과 달리 밝기와 사용 면적을 낮추고, 따뜻한 오프화이트 및 제한된 난색 포인트와 조합해 구별한다.

**현재 유력한 색 구조**

1. 배경: 순백보다 부드러운 따뜻한 오프화이트
2. 메인: 차분한 딥 틸 또는 블루그린 계열
3. 포인트: 햇빛과 작은 기쁨을 표현하는 옐로·앰버 또는 절제된 코랄
4. 텍스트: 완전한 검정보다 부드러운 잉크·차콜

메인색은 신뢰, 집중과 AI 분석의 정돈된 인상을 담당하고, 포인트색은 핵심 CTA 전체를 무조건 칠하는 색이 아니라 완료, 새 발견과 다음 행동을 알려주는 희소한 신호로 사용한다. 현재 주황빛 빨강을 남긴다면 면적과 채도를 줄인 코랄 계열로 조정해 이 포인트 역할만 맡긴다.

**위험과 윤리 점검**

- 색만으로 행동이나 상태를 전달하지 않고 문구, 아이콘 또는 형태를 함께 사용한다.
- 주요 CTA와 오류·삭제·실패 상태가 비슷한 의미로 보이지 않도록 구분한다.
- 최소 색 대비와 색각 다양성을 확인한다.
- 색을 바꾼 뒤 단기 클릭 증가만으로 브랜드 적합성을 판단하지 않는다.

**검증 방법**

- 단어 목록, OCR 저장 과정과 복습 화면에서 현재 색이 주는 인상을 각각 확인한다.
- 대표 사용자에게 화면을 먼저 보여준 뒤 `차분함`, `신뢰`, `활력`, `긴급함`, `부담` 가운데 어떤 인상을 받는지 묻는다.
- 기존안과 대안 시안에서 CTA 발견성, 상태 구분, 장시간 사용 피로와 제품 인상을 비교한다.
- WCAG 색 대비 기준과 색각 시뮬레이션으로 접근성을 점검한다.

**열린 질문**

- 사용자가 이 앱을 열 때 가장 먼저 느껴야 할 감정은 무엇인가?
- 학습을 마쳤을 때 남아야 할 감정은 무엇인가?
- 현재 주황빛 빨강은 브랜드의 주색이어야 하는가, 핵심 행동을 위한 강조색이어야 하는가?
- 일본어 학습 앱이라는 정체성을 색에 직접 담을 것인가, 학습 경험의 성격을 담을 것인가?

## P-004 · 앱의 말투와 폰트 방향

- 날짜: 2026-08-08
- 상태: 논의 중
- 근거가 된 책 기록: B-019
- 관련 결정: 없음

**행동 문제**

단어 입력과 OCR은 빠르게 처리되어야 하지만, 분석과 예문을 읽는 화면에서는 오래 머물 수 있어야 한다. 폰트가 지나치게 딱딱하면 조력자보다 교사나 업무 도구처럼 느껴질 수 있고, 반대로 너무 장난스러우면 언어 분석의 신뢰와 깊이가 약해질 수 있다.

**논의 요약**

현재까지 정의한 앱의 말투는 `어렵지 않게 다가오지만, 외국어를 깊이 이해하도록 믿을 만하게 돕는 현대적인 조력자`에 가깝다.

이에 따라 장식적인 세리프나 지나치게 기술적인 모노스페이스보다 모바일 가독성이 좋은 산세리프를 기본 후보로 본다. 정보 계층은 폰트를 계속 추가하기보다 크기, 굵기와 색으로 만드는 방향이 적합하다. 모노스페이스는 품사나 문법 구조처럼 기술적인 의미가 분명한 일부 요소에서만 제한적으로 검토할 수 있다.

라운드 고딕이 주는 `어렵지 않다`, `실수해도 괜찮다`는 정서는 이 앱의 조력자 역할과 잘 맞는다. 사용자는 카카오톡이나 라인에서 사용하는 것과 같은 친근한 폰트도 괜찮은 후보라고 보고 있다. 다만 지나치게 둥글거나 유아적인 인상이 외국어를 깊이 분석하는 기능의 신뢰감을 약하게 만들지는 더 살펴봐야 한다.

**적용 가설**

- 본문과 UI에는 모바일 가독성이 좋고 획이 지나치게 딱딱하지 않은 산세리프 한 가지를 우선 검토한다.
- 친근한 라운드 고딕과 중립적인 산세리프를 실제 목록·OCR·분석 화면에서 비교한다.
- 헤드라인과 본문을 같은 폰트 패밀리로 구성하고 크기와 굵기로 계층을 만들면 차분함과 일관성을 유지할 수 있다.
- 외국어 예문은 미적인 인상보다 일본어·한국어·영문 혼용 시 가독성과 문자 지원 품질을 우선한다.

**위험과 윤리 점검**

- 작은 화면에서 장시간 읽을 때 눈의 피로를 늘리지 않아야 한다.
- 친근함을 만들기 위해 지나치게 어린 사용자용 학습 앱처럼 보이게 하지 않는다.
- 굵기나 색만으로 정보의 의미를 구분해 저시력 사용자에게 불리한 구조를 만들지 않는다.

**검증 방법**

- 동일한 목록, OCR 결과와 분석 화면을 라운드 고딕 및 중립 산세리프로 각각 제작해 비교한다.
- `친근함`, `신뢰`, `집중`, `어려움`, `유아적임`에 대한 첫인상을 확인한다.
- 일본어·한국어·영문이 섞인 예문을 실제 모바일 크기로 읽게 하고 가독성과 피로도를 비교한다.

**열린 질문**

- 라운드 고딕의 친근함이 앱의 신뢰감을 해치지 않는 적절한 정도는 어디인가?
- 제목과 짧은 안내에만 더 부드러운 말투를 쓰고, 긴 본문은 중립적인 폰트로 구분할 필요가 있는가?
- 앱의 색상 방향과 결합했을 때 어떤 폰트가 `차분하지만 지루하지 않은 조력자`를 가장 잘 표현하는가?

## P-005 · 학습 화면에서 여백의 역할

- 날짜: 2026-08-08
- 상태: 논의 중
- 근거가 된 책 기록: B-020
- 관련 결정: 없음

**행동 문제**

이 앱은 단어 목록, OCR 결과, 뜻, 문법 분석과 예문처럼 많은 정보를 다룬다. 모든 정보를 한 번에 같은 무게로 보여주면 사용자는 무엇부터 읽고 행동해야 할지 알기 어렵다. 반대로 여백을 과도하게 늘리면 목록 탐색과 빠른 입력이 느려지고 불필요한 스크롤이 늘어날 수 있다.

**논의 요약**

앱에서 여백의 목적은 명품처럼 비싸 보이게 만드는 것이 아니다. 사용자가 지금 읽어야 할 단어·뜻·예문에 집중하게 하고, 복잡한 외국어 분석을 덜 어렵게 느끼게 하며, 오래 머무는 상세 화면의 피로를 낮추는 것이 목적이다.

화면마다 필요한 정보 밀도가 다르다.

- 단어 목록: 항목 사이를 구분할 여백은 필요하지만, 탐색 속도를 떨어뜨릴 만큼 넓어서는 안 된다.
- OCR 결과: 여러 단어를 한꺼번에 다루므로 무조건 비우기보다 선택한 문장·단어와 현재 행동을 강조하는 기능적 여백이 필요하다.
- 단어 상세·분석: 정의, 구조 분석과 예문 사이에 충분한 호흡을 주어 천천히 읽게 한다.
- 입력 과정: 넓은 여백보다 빠른 처리와 다음 행동의 발견성을 우선한다.

사용자의 결정 상태도 밀도를 정하는 기준이다. 이미 사용법을 아는 반복 사용자의 홈과 목록에서는 설명보다 빠른 탐색과 행동이 중요하다. 반면 OCR 첫 사용, 저장 전 확인, 결제와 데이터 삭제처럼 사용자가 결과를 판단해야 하는 화면에서는 감성적인 여백보다 조건과 결과를 충분히 설명해야 한다.

**적용 가설**

`모든 정보를 한 번에 같은 무게로 보여주지 않는다`를 기본 원칙으로 삼는다. 핵심 뜻과 현재 행동은 먼저 보여주고, 어원·문법 설명·추가 예문처럼 깊은 정보는 사용자가 필요할 때 펼쳐보게 한다. 여백과 단계적 공개를 함께 사용하면 기능을 없애지 않고도 복잡함을 낮출 수 있다.

**위험과 윤리 점검**

- 중요한 학습 정보나 선택지를 단순함을 이유로 숨기지 않는다.
- 여백을 늘려 장식적인 화면을 만드는 대신 실제 읽기와 행동의 흐름을 개선해야 한다.
- 모바일 화면에서 과도한 스크롤과 반복 동작을 만들지 않는다.

**검증 방법**

- 목록에서는 한 화면에 보이는 단어 수, 탐색 시간과 오탭을 비교한다.
- OCR 화면에서는 선택 문장, 저장 대상과 다음 행동을 사용자가 얼마나 빠르게 찾는지 확인한다.
- 상세 화면에서는 줄 간격과 섹션 간격별 읽기 편안함, 이해도와 피로도를 비교한다.
- 일본어·한국어·영문이 섞인 실제 모바일 화면에서 `1.5~2배` 줄 간격을 고정 적용하지 않고 가독성과 화면 길이를 함께 검증한다.

**열린 질문**

- 목록의 빠른 탐색과 상세 화면의 차분한 체류에 각각 적합한 밀도는 어느 정도인가?
- 기본으로 보여줄 학습 정보와 사용자가 펼쳐볼 보조 정보의 경계는 어디인가?
- 여백을 늘렸을 때 사용자가 화면을 편안하게 느끼는가, 정보가 부족하다고 느끼는가?

## P-006 · 첫 진입과 학습 화면의 시선 경로

- 날짜: 2026-08-08
- 상태: 논의 중
- 근거가 된 책 기록: B-021
- 관련 결정: 없음

**행동 문제**

새 사용자가 단어장에 처음 들어오면 저장된 단어가 없어 화면이 비어 있다. 이 순간 무엇을 할 수 있고 어디서 시작해야 하는지 알지 못하면, 앱의 기능을 경험하기 전에 이탈할 수 있다. 반대로 Z자·F자 구조를 모든 화면에 기계적으로 적용하면 실제 학습 과업과 모바일 사용성을 해칠 수 있다.

**논의 요약**

시선 패턴은 전 화면의 레이아웃 공식이 아니라, 특정 화면에서 사용자가 처음 무엇을 보고 다음에 무엇을 해야 하는지 설계하는 참고 도구로 사용한다.

가장 우선적인 적용 후보는 첫 진입의 빈 단어장이다. 아무것도 없는 상태 자체를 보여주는 데 그치지 않고, 앱이 도울 수 있는 일과 첫 행동을 자연스러운 순서로 이해하게 해야 한다.

기존 학습 화면에서는 과업에 따라 시선 흐름을 다르게 본다.

- 단어 목록: F자에 가까운 훑어보기를 고려해 단어와 핵심 뜻을 항목의 첫 줄과 시작 영역에 둔다.
- OCR 결과: 선택된 문장·단어, 인식 결과와 저장 행동 가운데 현재 단계에서 가장 먼저 확인할 요소 하나를 정한다.
- 단어 상세·분석: 단어와 핵심 뜻을 상단에서 바로 확인하게 하고, 각 섹션의 첫 문장에 분석의 결론을 둔다.

**적용 가설**

빈 단어장의 첫 시선 경로를 다음처럼 구성하는 안을 검토한다.

1. 이 화면이 비어 있는 이유와 앱이 도울 수 있는 일을 짧게 설명한다.
2. `책 페이지 촬영`, `문장 분석` 또는 `단어 직접 추가` 가운데 대표적인 첫 행동을 한 가지 주 행동으로 제시한다.
3. 나머지 입력 방식은 보조 행동으로 낮춰 선택 과부하를 줄인다.
4. 크기, 대비와 공간을 주 행동에 집중해 사용자가 다음 단계를 추측하지 않아도 되게 한다.

대표 행동을 무엇으로 정할지는 앱의 차별점과 실제 사용 빈도를 함께 봐야 한다. 사진 OCR이 차별점이라도 직접 입력을 원하는 사용자를 막아서는 안 된다.

**위험과 윤리 점검**

- Z자·F자 패턴을 정답처럼 적용하지 않는다.
- 강한 시각적 강조로 사용자가 원하지 않는 행동을 강요하지 않는다.
- 빈 상태에서 기능을 과장하거나 사용자의 불안을 자극하지 않는다.
- 모바일의 엄지손가락 도달 범위와 접근성을 시선 순서와 함께 고려한다.

**검증 방법**

- 처음 보는 사용자가 빈 단어장에서 무엇을 할 수 있다고 이해하는지 묻는다.
- 도움 없이 첫 단어 추가 또는 OCR 시작까지 걸리는 시간과 잘못 누른 행동을 확인한다.
- 단어 목록, OCR과 상세 화면에서는 첫 응시점 대신 첫 탭, 스크롤과 과업 완료 흐름을 함께 관찰한다.
- 필요하면 대표 화면에서 간단한 시선 추적 또는 클릭 히트맵을 사용한다.

**열린 질문**

- 빈 단어장에서 가장 먼저 권할 행동은 사진 OCR, 직접 입력, 문장 분석 중 무엇인가?
- 앱의 차별점을 설명하는 문구와 바로 시작하는 행동 사이의 적절한 비중은 무엇인가?
- 첫 단어가 추가된 뒤 빈 상태의 안내를 어떤 학습 흐름으로 전환할 것인가?

## P-007 · 첫 빈 단어장에서 외국어 독서의 가능성 보여주기

- 날짜: 2026-08-08
- 상태: 논의 중
- 근거가 된 책 기록: B-022
- 관련 결정: 없음

**행동 문제**

이 앱은 사용자를 대신해 공부해주는 제품이 아니다. 사용자가 직접 책을 읽고, 사진을 찍고, 단어와 표현을 살펴봐야 가치를 얻을 수 있다. 친구들과의 대화에서 이러한 자기주도적 전제가 제품의 니즈를 좁힐 수 있다는 의문이 제기됐다.

특히 첫 진입 시 단어장이 비어 있으면 사용자는 앱이 무엇을 바꿔줄 수 있는지 경험하지 못한 상태에서 먼저 행동해야 한다. 학습 의지가 충분하지 않으면 첫 단어를 추가하기 전에 이탈할 수 있다.

**논의 요약**

첫 화면은 막연하게 `공부하세요`라고 권하거나, 앱이 노력 없이 언어를 익히게 해준다고 약속해서는 안 된다. 사용자가 이미 가지고 있는 `외국어 책을 읽고 싶다`는 욕구에 연결하고, 가장 큰 장애물인 모르는 단어와 표현을 빠르게 이해할 수 있다는 가능성을 보여주는 편이 적합하다.

첫 빈 단어장의 중심 인상은 다음에 가깝다.

> 외국어 책, 읽을 수 있어요.

이를 단순한 구호로 끝내지 않고 `책 페이지 → 궁금한 문장 선택 → 단어와 표현을 이해함`의 짧은 시각적 흐름으로 보여준다. 일반적인 공부 일러스트나 웃는 사람의 스톡 사진보다 앱의 실제 입력과 결과를 축약한 이미지가 차별점을 더 정확하게 전달할 수 있다.

**적용 가설**

- 빈 상태에서 사용자가 촬영한 책 페이지가 어떻게 이해 가능한 정보로 바뀌는지 작은 데모 또는 전후 장면으로 보여준다.
- 중심 문구는 학습을 명령하기보다 외국어 독서의 장벽이 낮아진다는 결과를 표현한다.
- 대표 행동은 사진 OCR을 우선 후보로 두되 직접 입력과 문장 분석도 보조 행동으로 접근할 수 있게 한다.
- 첫 행동 직후 실제 단어나 문장 하나를 이해하는 작은 성공을 빠르게 경험하게 한다.

**위험과 윤리 점검**

- 사용자의 노력 없이 외국어를 습득할 수 있다고 과장하지 않는다.
- `외국어 책을 읽을 수 있다`는 약속은 번역의 완전성보다 읽기 허들을 낮춰준다는 범위로 표현한다.
- 자기주도 학습 의지가 낮은 사용자를 죄책감이나 불안으로 자극하지 않는다.
- 시각적 데모가 실제 앱에서 제공하지 않는 결과나 속도를 암시하지 않게 한다.

**검증 방법**

- 처음 보는 사용자에게 첫 화면만 보여주고 앱이 무엇을 해주는지 설명하게 한다.
- `공부를 해야 하는 앱`, `외국어 책을 읽도록 돕는 앱`, `번역 앱` 가운데 어떤 인상을 받는지 확인한다.
- 빈 상태의 시각적 데모 유무에 따라 첫 OCR 시작률과 첫 단어 저장률을 비교한다.
- 자기주도 학습 의지가 높지 않은 사용자도 첫 결과에서 가치를 느끼는지 인터뷰한다.

**열린 질문**

- 실제 핵심 사용자는 외국어 학습 의지가 높은 사람인가, 외국어 콘텐츠를 이해해야 할 구체적 상황이 있는 사람인가?
- `외국어 책, 읽을 수 있어요`가 기대를 높이면서도 과장으로 느껴지지 않는 구체적인 표현은 무엇인가?
- 첫 성공 경험 이후 사용자가 스스로 다시 돌아올 이유를 어떤 기능이 만들어야 하는가?

## P-008 · 화면별 핵심 메시지와 행동 계층

- 날짜: 2026-08-08
- 상태: 논의 중
- 근거가 된 책 기록: B-023
- 적용 수준: 변형 적용
- 관련 결정: 없음

**행동 문제**

앱에는 사진 OCR, 직접 입력, 문장 분석, 단어 상세와 복습처럼 여러 기능이 있다. 이 기능을 같은 무게로 한꺼번에 보여주면 사용자는 앱의 차별점과 현재 해야 할 행동을 찾기 어렵다. 반대로 전환 중심의 책 원칙을 그대로 적용해 한 행동만 강요하면 사용자의 다양한 학습 방식과 필요한 확인 절차를 해칠 수 있다.

**논의 요약**

화면마다 사용자가 반드시 이해하거나 해야 하는 한 가지를 먼저 정하고, 핵심 메시지·보조 설명·세부 정보의 순서로 시각적 계층을 만든다. 이 원칙은 기능 삭제가 아니라 우선순위 설계로 사용한다.

첫 빈 단어장에서는 다음 구조를 검토한다.

1. 핵심 메시지: `외국어 책, 읽을 수 있어요.` 또는 `모르는 표현 때문에 책을 덮지 마세요. 책 속 단어와 문장을 한 번에 이해해보세요.`
2. 보조 설명: 책 페이지를 촬영하면 단어와 표현의 구조를 이해할 수 있다는 짧은 설명
3. 세부 정보와 보조 행동: 직접 단어 추가, 문장 분석과 실제 결과 예시

대표 행동은 사진 OCR을 우선 후보로 두되 직접 입력과 문장 분석을 막지 않는다. OCR도 무조건 한 단계로 축약하지 않고 `책 페이지 촬영 → 인식 결과 확인 → 저장`처럼 오류를 바로잡는 데 필요한 확인은 유지한다.

정보 계층은 다른 화면에도 다음처럼 적용할 수 있다.

- 단어 상세: 현재 필요한 뜻 → 표현 구조와 대표 예문 → 어원·추가 예문·문법 설명
- 단어 목록: 단어 또는 표현 → 핵심 뜻과 복습 상태 → 날짜·출처 같은 메타 정보
- OCR 결과: 현재 선택한 문장과 단어 → 인식·분석 결과 → 저장 옵션과 세부 설정

화면 설계 때마다 `이 화면에서 사용자가 반드시 이해하거나 해야 하는 한 가지는 무엇인가?`를 먼저 묻는다.

**맥락 적합성 기준**

책에는 릴스, 소개 페이지, 판매와 전환을 전제로 한 표현이 많아 단어장 앱과 맞지 않는 부분도 있다. 따라서 책의 용어를 그대로 가져오기보다 다음처럼 판단한다.

- 학습자가 정보를 이해하는 순서를 돕는 시각적 계층은 변형 적용한다.
- 사용자의 입력 부담을 줄이는 흐름은 오류 수정 가능성과 학습 주도권을 보존할 때 적용한다.
- 구매 전환, 긴급성, 손실 회피처럼 학습의 질이나 자율성을 해칠 수 있는 장치는 참고만 하거나 적용을 보류한다.
- 각 책 기록은 앱에서의 `직접 적용`, `변형 적용`, `참고만`, `적용 보류` 가운데 하나로 분류한다.

**적용 가설**

화면별 핵심 메시지와 대표 행동을 하나씩 정하면 기능을 줄이지 않고도 처음 보는 사용자가 앱의 목적과 다음 행동을 더 빠르게 이해할 수 있다. 상세 정보는 필요할 때 접근할 수 있게 해 빠른 입력과 천천히 탐색하는 학습 경험을 모두 지원한다.

**위험과 윤리 점검**

- 주 행동의 강조가 다른 입력 방식의 발견성을 지나치게 낮추지 않게 한다.
- 저장 전 인식 오류 확인과 되돌리기 같은 안전 단계를 전환율을 이유로 없애지 않는다.
- `외국어 책을 읽을 수 있다`는 메시지가 노력 없는 습득이나 완전한 번역을 암시하지 않게 한다.
- 책의 사례와 앱의 사용자·과업이 다를 때는 적용하지 않는 선택을 기록한다.

**검증 방법**

- 처음 보는 사용자가 각 화면의 목적과 다음 행동을 한 문장으로 설명할 수 있는지 확인한다.
- 빈 단어장에서 첫 OCR 시작, 직접 입력과 문장 분석의 발견률을 함께 관찰한다.
- OCR 저장 전 사용자가 인식 오류를 발견하고 수정할 수 있는지 확인한다.
- 시각적 단순화가 학습 정보 누락이나 오해로 이어지는지 인터뷰한다.

**열린 질문**

- 빈 단어장의 핵심 문구는 가능성을 강조하는 문장과 구체적 기능을 설명하는 문장 중 어느 쪽이 더 정확한가?
- 사진 OCR을 주 행동으로 강조했을 때 직접 입력과 문장 분석은 어느 수준으로 보여야 하는가?
- 화면별 핵심 목적을 제품 전체에서 일관되게 관리할 방법은 무엇인가?

## P-009 · 앱 화면을 하나의 학습 시나리오로 연결하기

- 날짜: 2026-08-08
- 상태: 논의 중
- 근거가 된 책 기록: B-024
- 적용 수준: 변형 적용
- 관련 결정: 없음

**행동 문제**

첫 화면, OCR 입력, 단어·표현 상세와 복습 화면이 각각 잘 만들어져도 서로 다른 제품처럼 느껴지면 사용자는 앱의 목적과 학습 흐름을 다시 해석해야 한다. 특히 AI 기능이 화면마다 다른 말투와 가치로 제시되면 도구의 신뢰와 학습 주도권이 약해질 수 있다.

**논의 요약**

책의 프로필·피드·상세페이지 흐름을 앱에서는 다음과 같이 번역한다.

- 첫 화면·빈 단어장: 이 앱은 누구를, 어떻게 돕는가
- OCR·입력 화면: 앱이 지금 무엇을 해주는가
- 단어·표현 상세: 사용자가 어떤 이해를 얻는가
- 복습 화면: 얻은 이해가 어떻게 꾸준한 학습으로 이어지는가

모든 화면을 동일하게 만들 필요는 없지만 색, 말투와 가치의 약속은 이어져야 한다.

- 색: 같은 디자인 토큰과 강조 규칙을 사용하되 화면의 과업에 따라 비율과 강도를 조절한다.
- 말투: 사용자를 평가하는 선생님보다 이해를 돕는 조력자의 목소리를 유지한다.
- 가치: AI의 화려함보다 외국어를 더 깊고 쉽게 이해하게 한다는 목적을 보여준다.
- 주도권: AI가 정답을 강요하지 않고 사용자가 확인, 수정과 추가 탐색을 할 수 있게 한다.

**적용 가설**

사용자가 `외국어 콘텐츠를 발견함 → 사진이나 문장을 입력함 → 표현을 이해함 → 저장하고 다시 만남`이라는 하나의 시나리오를 화면 전체에서 경험하면, 기능이 많아도 서로 관련 없는 도구의 모음이 아니라 같은 학습을 돕는 흐름으로 인식할 수 있다.

**위험과 윤리 점검**

- 시각적 일관성을 위해 입력과 상세 화면의 서로 다른 속도와 정보 밀도를 없애지 않는다.
- 오류·경고·삭제처럼 주의가 필요한 상황에서는 평소보다 명확하고 직접적인 말투를 사용한다.
- AI 결과의 불확실성을 숨기면서 브랜드의 자신감만 강조하지 않는다.
- SNS와 판매 전환에서 사용한 일관성 개념을 앱의 모든 접점에 기계적으로 적용하지 않는다.

**검증 방법**

- 서로 다른 화면 몇 개를 순서 없이 보여주고 같은 앱으로 인식하는지 확인한다.
- 첫 화면부터 OCR 저장과 상세 탐색까지 사용자가 앱의 역할을 어떻게 설명하는지 관찰한다.
- 화면별 문구가 조력자, 선생님, 번역기와 AI 챗봇 중 어떤 인상을 주는지 묻는다.
- 색과 구성은 일관되지만 과업별 속도 차이가 충분히 유지되는지 사용성 테스트로 확인한다.

**열린 질문**

- 앱 전체를 관통하는 한 문장의 가치 약속은 무엇인가?
- 빈 단어장에서 첫 저장, 상세 탐색과 복습까지 어떤 시각적·언어적 요소를 반복할 것인가?
- 오류와 AI의 불확실성을 조력자다운 말투로 어떻게 설명할 것인가?

## P-010 · 첫 빈 단어장의 감정 시나리오

**행동 문제**

첫 빈 단어장에서 기능과 입력 방식부터 설명하면 사용자는 앱이 자신의 외국어 독서 문제와 어떤 관련이 있는지 이해하기 전에 정보를 받아야 한다. 반대로 문제와 감정을 지나치게 강조하면 학습 의지가 낮다는 죄책감이나 과장된 기대를 만들 수 있다.

**논의 요약**

시각 시나리오 공식은 모든 학습 화면이 아니라 첫 빈 단어장, 온보딩과 앱 소개 콘텐츠에 변형 적용한다.

1. 문제: `모르는 표현이 나올 때마다 검색하느라 책의 흐름이 끊기나요?`
2. 공감: `한 문장을 이해하려다 단어 검색만 늘어나는 건 자연스러운 일이에요.`
3. 해결 방향: `책 페이지를 찍고, 궁금한 문장의 단어와 표현 구조를 한곳에서 살펴보세요.`
4. 증거: 실제 책 페이지가 단어·표현 분석으로 바뀌는 짧은 데모
5. 행동: `책 한 페이지로 시작하기`

후기와 사용 통계가 충분하지 않은 단계에서는 근거를 꾸미지 않고 실제 기능의 전후 장면을 증거로 사용한다. `외국어 책, 읽을 수 있어요`라는 가능성을 구체적인 첫 경험으로 연결한다.

**적용 가설**

기능 목록보다 사용자가 겪는 독서의 중단 상황에서 시작하면 앱의 가치를 더 빠르게 이해할 수 있다. 이어 실제 기능 결과와 부담이 작은 첫 행동을 보여주면 자기주도 학습을 명령하지 않으면서도 첫 시도를 도울 수 있다.

**위험과 윤리 점검**

- 공부하지 않는 사람이라는 죄책감을 만들지 않는다.
- 사진 한 장이면 모든 표현을 완벽하게 이해한다고 과장하지 않는다.
- 후기와 수치는 검증된 자료만 사용한다.
- 저장과 복습을 모든 사용자의 필수 행동처럼 강요하지 않는다.
- 가입이나 클릭보다 사용자가 첫 표현을 실제로 이해했는지를 중요한 결과로 본다.

**검증 방법**

- 첫 화면만 본 사용자가 앱을 번역기, 단어장과 외국어 독서 조력자 중 무엇으로 이해하는지 확인한다.
- 기능 설명 중심 화면과 시나리오 중심 화면의 첫 OCR 시작률과 첫 표현 이해 여부를 비교한다.
- 문제와 공감 문구가 안도감, 부담감 또는 과장 가운데 어떤 감정을 만드는지 인터뷰한다.
- 실제 데모가 기능의 결과와 한계를 정확하게 전달하는지 확인한다.

**열린 질문**

- 문제를 얼마나 구체적으로 표현해야 공감은 생기고 불안 자극은 피할 수 있는가?
- 첫 화면의 증거로 어떤 실제 책 페이지와 분석 결과를 보여주는 것이 가장 대표적인가?
- 첫 행동 뒤 사용자가 `표현 하나를 이해했다`고 느끼는 순간을 어떻게 확인할 것인가?

## P-011 · 쓰레드에서 자기 관련 감정을 만드는 문장

## P-012 · 앱 문장을 짧고 구체적으로 다듬는 기준

- 날짜: 2026-08-08
- 상태: 논의 중
- 근거가 된 책 기록: B-027
- 적용 수준: 변형 적용
- 관련 결정: 없음

**행동 문제**

버튼과 안내 문구가 추상적이거나 길면 사용자는 행동 뒤에 어떤 결과가 생기는지 추측해야 한다. 그러나 모든 설명을 짧게 줄이면 OCR 오류, 분석 결과와 학습 정보의 정확성을 충분히 전달하지 못할 수 있다.

**논의 요약**

빈 상태, 온보딩과 버튼에서는 행동과 결과가 보이는 짧고 구체적인 문장을 우선한다.

- `분석` → `문장 구조 살펴보기`
- `저장 완료` → `단어장에 저장했어요`

오류 메시지는 문제만 알리지 않고 사용자가 복구할 수 있는 다음 행동을 함께 설명한다. 단어·표현 상세에서는 핵심 뜻을 먼저 짧게 보여주되 정확한 이해에 필요한 분석과 예문은 아래에서 충분히 제공한다.

한국어에서는 `당신`을 직접 반복하기보다 사용자의 현재 행동과 상황을 문장의 주어로 삼는다.

**적용 가설**

행동과 결과가 명확한 문구는 버튼을 누른 뒤 일어날 일을 예측하게 하고, 짧은 핵심 문장과 단계적 상세 설명의 조합은 빠른 입력과 깊은 이해를 함께 지원한다.

**위험과 윤리 점검**

- 간결함을 이유로 중요한 조건과 불확실성을 숨기지 않는다.
- 강한 동사를 명령이나 압박으로 사용하지 않는다.
- AI 분석이 확정적인 정답인 것처럼 표현하지 않는다.
- 검증되지 않은 수치와 성과를 구체성의 장치로 사용하지 않는다.

**검증 방법**

- 버튼 라벨만 보고 결과를 예측할 수 있는지 묻는다.
- 오류 메시지를 본 사용자가 도움 없이 복구할 수 있는지 확인한다.
- 상세 설명을 줄였을 때 이해도와 오해가 어떻게 변하는지 비교한다.
- 한국어, 일본어와 영문이 섞인 화면에서 문장 길이와 가독성을 실제 기기로 확인한다.

**열린 질문**

## P-013 · 쓰레드와 첫 빈 화면의 EPSA 구조

- 날짜: 2026-08-08
- 상태: 논의 중
- 근거가 된 책 기록: B-028
- 적용 수준: 쓰레드·카드뉴스는 직접 적용 | 첫 빈 단어장은 변형 적용 | 반복 학습 화면은 참고만
- 관련 결정: 없음

**행동 문제**

앱의 기능을 정보부터 설명하면 사용자는 그것이 자신의 독서와 학습에서 어떤 답답함을 덜어주는지 느끼기 어렵다. 반대로 불안과 결핍을 지나치게 강조하면 외국어 학습에 대한 부담과 죄책감을 키울 수 있다.

**논의 요약**

쓰레드나 카드뉴스에서는 EPSA를 다음처럼 직접 활용할 수 있다.

- E: `모르는 표현이 나올 때마다 검색하느라 책의 흐름이 끊기면 답답하죠?`
- P: `단어를 하나씩 따로 찾으면 문장 안에서 어떤 역할을 하는지 놓치기 쉽습니다.`
- S: `책 페이지를 촬영하고, 문장 속 단어와 표현 구조를 한곳에서 살펴보세요.`
- A: `다음에 막히는 페이지가 나오면 한 장으로 시작해보세요.`

첫 빈 단어장에서는 불안을 앞세우기보다 `외국어 책을 이해할 수 있다`는 가능성과 검색 부담이 줄어드는 안도감을 중심 감정으로 삼는다. 반복해서 사용하는 입력, 목록과 상세 화면에는 EPSA 전체를 넣지 않고 필요한 행동과 정보 계층만 적용한다.

**적용 가설**

기능이 아니라 사용자가 겪는 실제 독서의 단절에서 시작하면 앱의 사진 입력과 문장 분석 기능이 왜 필요한지 더 쉽게 이해할 수 있다. 첫 빈 화면에서 안도감과 가능성을 먼저 보여주면 학습 부족을 지적하지 않고도 첫 페이지 촬영을 유도할 수 있다.

**위험과 윤리 점검**

- 사용자가 공부를 게을리하거나 의지가 부족하다는 인상을 주지 않는다.
- `이 앱만 있으면 외국어 책을 읽을 수 있다`처럼 결과를 과장하지 않는다.
- AI 분석을 정답이나 교사의 대체물로 약속하지 않고 이해를 돕는 조력자로 표현한다.
- 행동을 강요하거나 놓치면 손해라는 압박을 만들지 않는다.
- 반복 학습 화면에 감정 자극을 계속 노출해 피로를 만들지 않는다.

**검증 방법**

## P-014 · 불편 증폭 대신 문제 구체화하기

## P-015 · 첫 빈 단어장에 맥락과 질문 만들기

- 날짜: 2026-08-08
- 상태: 논의 중
- 근거가 된 책 기록: B-030
- 적용 수준: 쓰레드·카드뉴스·앱 소개는 직접 적용 | 첫 빈 단어장·온보딩은 압축하여 변형 적용 | 새로운 기능 소개는 변형 적용 | 반복 학습·목록·상세 화면은 참고만 | 오류·결제·필수 안내는 적용하지 않음
- 관련 결정: 없음

**행동 문제**

아무 단어도 없는 첫 화면에서 기능이나 버튼만 보여주면 사용자는 왜 페이지를 촬영해야 하는지, 그 행동이 자신의 외국어 독서에 어떤 도움을 주는지 이해하기 어렵다. 반대로 긴 설명과 질문을 모두 표시하면 첫 행동 전에 읽어야 할 내용이 많아진다.

**논의 요약**

첫 빈 단어장의 SCQA 초안은 다음과 같다.

- S: `외국어 책을 읽다 보면 모르는 단어나 표현을 만나게 됩니다.`
- C: `하나씩 검색하다 보면 읽던 흐름이 끊기고, 문장 속 쓰임까지 이해하기 어렵습니다.`

- A: `책 페이지를 촬영해 단어의 뜻과 표현 구조를 함께 확인해보세요.`
- CTA: `첫 페이지 촬영하기`

실제 화면에는 네 단계를 모두 문장으로 표시하지 않고 다음처럼 압축할 수 있다.

> 책의 흐름을 놓치지 말고 읽어보세요.
> 페이지를 촬영하면 단어의 뜻과 문장 속 표현을 함께 살펴볼 수 있어요.

CTA는 `첫 페이지 촬영하기`로 둔다. Q를 반드시 물음표가 있는 문장으로 표현할 필요는 없다. 사용자의 머릿속에 자연스럽게 질문이 생기도록 상황과 문제를 배열하고, CTA가 그 답이 되게 만들 수 있다.

### 색상 결정 과정의 SCQA

- S: 현재 앱은 와인 배달 앱에서 가져온 강렬한 주황 계열을 사용한다.
- C: 엣지는 있지만 단어를 복습하고 오래 머무르기에는 다소 강하고 친목 앱처럼 느껴질 수 있다.

**위험과 윤리 점검**

- 호기심을 만들기 위해 앱이 할 수 있는 일을 숨기거나 답을 늦추지 않는다.
- 앱이 외국어 책의 이해를 보장한다고 과장하지 않는다.

**검증 방법**

## P-016 · 이유와 결과가 보이는 앱 CTA

- 날짜: 2026-08-08
- 상태: 논의 중
- 근거가 된 책 기록: B-004, B-031
- 적용 수준: 직접 적용
- 관련 결정: 없음

**행동 문제**

추상적인 버튼은 사용자가 행동 뒤에 어떤 결과가 생기는지 추측하게 한다. 반대로 손실, 희소성과 즉시성을 과도하게 사용하면 학습 행동을 돕기보다 사용자를 조급하게 만들 수 있다.

**논의 요약**

앱에서는 손실과 희소성보다 행동 후 결과와 사용자의 주도권을 보여주는 CTA가 적합하다.

- `OCR 시작` → `사진에서 단어 가져오기`
- `저장` → `선택한 12개 단어 저장하기`
- `분석` → `문장 구조 살펴보기`
- `시작` → `오늘 복습 시작하기`
- 첫 빈 화면의 CTA → `첫 페이지 촬영하기`

버튼만으로 모든 이유를 설명하지 않는다. 버튼 앞의 설명이 이유와 기대 결과를 만들고, 버튼은 단 하나의 행동을 명확히 표시한다. 특히 저장이나 분석 전에는 대상과 결과를 분명히 보여준다. `계속`보다 `12개 단어 저장하기`가 사용자의 결심을 돕는다.

**적용 가설**

CTA 앞의 문맥이 행동의 이유를 만들고 버튼 라벨이 대상과 결과를 구체적으로 보여주면, 사용자는 강요받는 느낌 없이 다음 행동을 예측하고 선택할 수 있다.

**위험과 윤리 점검**

- 거짓 희소성, 인위적인 마감과 놓치면 손해라는 압박을 사용하지 않는다.
- 검증되지 않은 사용자 수와 권위를 CTA 근거로 사용하지 않는다.
- 버튼 라벨과 실제 실행 결과가 일치해야 한다.
- 모든 이유를 버튼 안에 넣어 라벨이 지나치게 길어지지 않게 한다.
- 사용자가 취소하거나 이전 단계로 돌아갈 선택권을 숨기지 않는다.

**검증 방법**

- 버튼 라벨만 보고 실행 결과를 예측할 수 있는지 묻는다.
- `계속` 같은 추상적 문구와 결과 중심 문구의 완료율과 오작동률을 비교한다.
- 버튼 앞의 설명을 제거했을 때 행동 이유의 이해도가 달라지는지 확인한다.
- 모바일 화면과 여러 언어에서 라벨이 잘리거나 지나치게 길어지지 않는지 검증한다.

**열린 질문**

- 현재 앱에서 결과를 가장 예측하기 어려운 CTA는 무엇인가?
- 선택 개수처럼 변하는 값을 버튼에 어느 범위까지 표시할 것인가?
- 주 CTA와 취소·건너뛰기 같은 보조 행동의 시각적 위계를 어떻게 정할 것인가?

- 단어 목록·복습 화면: 감정 구조 없이 현재 상태와 다음 행동을 명확히 보여준다.
- 표현 상세 화면: 핵심 뜻을 먼저 보여주고 분석·예문을 단계적으로 제공한다.
- 오류 화면: 호기심이나 설득 없이 원인과 복구 행동을 즉시 안내한다.

핵심은 모든 화면에 구조를 넣는 것이 아니라 같은 제품 약속을 화면의 목적에 맞게 번역하는 것이다.

**적용 가설**

제품의 중심 약속을 유지하면서 체류 시간과 행동 목적에 맞게 문장 구조를 바꾸면, 외부 콘텐츠에서는 관심과 이해를 만들고 앱 내부에서는 차분하고 직접적인 사용 경험을 유지할 수 있다.

**위험과 윤리 점검**

- 짧은 접점이라는 이유로 불안과 손실을 과장하지 않는다.
- 반복 화면에 매번 설득 문구를 노출하지 않는다.
- 콘텐츠 구조의 전환 과정에서 제품이 제공하지 않는 결과를 새로 약속하지 않는다.
- 플랫폼별 경험칙을 보편적인 규칙으로 적용하지 않는다.
- 오류와 필수 안내에서는 정보보다 이야기 구조를 우선하지 않는다.

**검증 방법**

- 같은 메시지의 쓰레드, 빈 화면과 OCR 안내 버전을 사용자에게 보여주고 각 접점의 목적을 정확히 이해하는지 확인한다.
- 반복 화면의 설득 문구 유무가 피로감과 행동 완료에 미치는 영향을 비교한다.
- 외부 콘텐츠에서 유입된 사용자가 앱 내부에서 같은 제품 약속을 경험하는지 인터뷰한다.
- 각 접점에서 다음 행동까지 걸리는 시간과 이탈 지점을 관찰한다.
